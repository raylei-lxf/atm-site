# Agent Task Manager

**Agent Task Manager connects a local task board with AI assistants through MCP so they can work with task context. Tasks and conversations stay traceable in local files, putting you in control of your work.**

**Free during public beta.**

## Downloads

- **npm — available:** [agent-task-manager-core](https://www.npmjs.com/package/agent-task-manager-core)
- **VS Code extension:** Marketplace listing currently unavailable.
- **Open VSX:** not yet published.

Install the core with Node.js 18 or later:

```sh
npm install -g agent-task-manager-core
atm
```

`atm` starts the local core and opens the welcome page. The core works independently of VS Code; see the welcome page to configure your AI client.

## How it works

1. Install the core from npm and run `atm`.
2. Set up your AI client from the welcome page and describe the work you want to do.
3. Use the local board to follow tasks and revisit their conversation history.
